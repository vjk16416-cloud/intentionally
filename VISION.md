# Intentionally Vision

## Mission

Intentionally exists to change dating from fake, passive, time-wasting interactions into structured, meaningful conversations that help people make better decisions.

## North Star

Help two people have a better first conversation than modern dating usually allows.

## Brand Feeling

Users should feel:

- Excited
- Calm
- Curious
- Safe
- Hopeful

## Product Promise

Talk before you text.  
Decide with intention.  
Move forward only when it feels mutual.

## Product Principles

1. Better matches over more matches.
2. Structure should reduce anxiety, not create pressure.
3. Rejection should feel respectful, private, and blame-free.
4. Chat should feel like continuing a conversation, not starting from zero.
5. The app should feel human, calm, and intentional.
6. If a feature encourages endless swiping or passive time-wasting, it does not belong.

## Possible Headlines

- The dating app changing the way we date.
- Finally — structure for modern dating.
- Less swiping. Better conversations.
- Dating that feels calmer, safer, and more real.

## Feature Filter

Before building anything, ask:

Does this help people make a better decision about each other?

If yes, consider it.

If no, defer it.

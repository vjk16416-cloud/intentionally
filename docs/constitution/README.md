# Constitution

This folder contains supporting repository notes about mission, decision rules, non-negotiables and operating philosophy.

These files are **not a competing source of truth**. Founder-approved product, UX, safety, technical-direction and roadmap decisions live in the `Intentionally_ChatGPT_Safe` Google Drive vault and follow this authority order:

1. `08_Decisions/Decision Log.md`
2. `00_Start_Here/Current App State.md`
3. `00_Start_Here/Start Here.md`
4. Relevant feature notes
5. Roadmap notes
6. Research notes
7. Older prompts or loose notes

If a constitution note conflicts with the Drive vault, the Drive vault wins. Treat unsupported statements here as working guidance or draft thinking until they are recorded in the appropriate Drive source and Founder-approved where required.

See [`../second-brain/README.md`](../second-brain/README.md) for the repository mirror of the authority model.

Use this folder for supporting principles that should change rarely and only with clear Founder intent. Do not use it to silently create product decisions, architecture standards or implementation scope.

Existing and future documents may include:

- `mission.md`
- `product-principles.md`
- `decision-rules.md`
- `non-negotiables.md`
- `relationship-quality-over-growth.md`
